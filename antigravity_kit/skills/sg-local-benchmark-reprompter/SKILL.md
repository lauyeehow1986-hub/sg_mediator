# Closed-Loop Local Benchmark & Reprompt Skill

## When to Use
Use this skill whenever the user uploads or pastes `antigravity_reprompt_bundle.json` generated by `benchmark_local.bat`.

## Step-by-Step Resolution Loop
1. Inspect `phi_scrubbed_discrepancies` in `antigravity_reprompt_bundle.json` and categorize each failure (`FALSE_NEGATIVE_OR_ASSERTION_MISMATCH`, `FALSE_POSITIVE`, `PROVENANCE_COPY_PASTE_MISMATCH`).
2. Query `sg-clinical-router-mcp` (`expand_clinical_context`) to retrieve authoritative Singapore ACE/MOH/TOSP thresholds and synonyms.
3. Update `config/sg_clinical_rules.yaml` and `config/sg_ontology_seed.csv`.
4. Re-run `python src/benchmark_engine.py --input-dir sample_inbox --gold-file sample_inbox/gold_labels.csv --output-dir output_benchmark` and verify that F1 and Copy-Paste Provenance Accuracy reach 100% on the test cases without introducing regressions.
